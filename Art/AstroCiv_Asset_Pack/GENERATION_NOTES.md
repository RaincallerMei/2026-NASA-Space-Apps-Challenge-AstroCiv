# Generation and normalization record

Method: built-in image generation, followed by deterministic Pillow/NumPy cleanup, palette mapping, exact geometry, packing and validation. The attached AstroCiv board supplied appearance. The existing AstroCiv UI/UX guide supplied interaction and terminology rules. The board takes precedence for dark navy surfaces.

All illustration requests specified authentic chunky 16-bit pixel clusters, navy outlines, lavender shadows, white/cyan architecture, upper-left illumination, a fixed elevated three-quarter view and transparent background. No labels, floor scenery or cast shadows were requested in object masters. Output resolution from generation was not treated as proof of native pixel alignment.

| Master | Prompt specification |
|---|---|
| architecture.png | Three separate complete objects: tiered rounded command hub with antenna/triangular emblem/front airlock; cylindrical habitat; white frame greenhouse with cyan glass and green plant rows. The initial hub had satellite modules; a corrective generation removed all attached modules and corridors. |
| equipment.png | Three isolated objects: rectangular battery cabinet with charge strips/lightning, dish/mast/base, sapphire solar array on white supports; architecture master used as style reference. |
| shelter_airlock_rover.png | Low gray mound with reinforced cyan entrance, compact cylinder airlock, six-wheel white rover with cargo/antenna/yellow lights. Reference board and normalized architecture used together. |
| functional.png | Laboratory with telescope/flask, life support with tanks/pipes/fan/droplet, open garage with charging post; matched normalized architecture. |
| astronaut_poses.png | Same friendly astronaut in idle, walk, wave, tablet and repair poses; full bodies, fixed scale, wide gutters. Detached wave effect removed during export. |
| astronaut_walk.png | Four rows of four walk phases: SE, SW, NW, NE. Rear-facing rows show helmet back/backpack. Distinct contact/passing poses requested. Individual frames normalized to 32×48 with common baseline. |
| terrain_props.png | Three sizes of crater and three sizes of angular rock cluster, isolated, cool silver palette. Soft alpha halos were discarded. Mars variants are palette conversions. |
| backdrops_ground.png | Separate lunar ridge, Martian ridge and flat lunar regolith swatch. Ground sampled from the swatch interior, contrast reduced and mirror-tiled for exact periodicity. |
| earth.png | Isolated blue Earth, green continents, white clouds, navy outline, no glow, intended 64×64 export. Stylized, not cartographically accurate. |
| corridor_source.png | Two white segmented tubes on opposite 2:1 grid axes, cyan windows, navy outlines. Used as design source for simplified exact socket geometry. |

Final assets are not crops of the original concept board. Source groups contain only small coherent sets. Thumbnails and portrait are derived from final exported sprites. UI borders, resource/action icons, font, decals, shadows and dust masks are deterministic. Atlas rectangle metadata uses both top-left image and bottom-left Unity coordinates.
