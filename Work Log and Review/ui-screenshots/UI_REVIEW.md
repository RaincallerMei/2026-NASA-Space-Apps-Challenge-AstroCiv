## Visible issues

| Issue | Evidence |
|---|---|
| Story and gameplay share the same layout | Intro, photo cards, ending and Blueprint retain the large grid and build controls |
| Story presentation has little visual focus | Story text occupies the lower-right area; most of the screen remains the map |
| Buildings have weak visual identity | Tiny letter abbreviations and coloured blocks carry the building information |
| Mission feedback lacks emphasis | The storm uses text in the same layout; success/failure debrief is a small lower-right text block |
| Information hierarchy is weak | Resource rows, instructions, build buttons and story text compete without clear grouping |
| Missing scene artwork | Bedroom, photo cards and observation window are still labelled placeholders |

These captures document the current functional greybox. Final art/layout decisions remain for Opus/team. Unity was returned to stopped Boot.
